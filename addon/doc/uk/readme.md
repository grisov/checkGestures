# NVDA Check Input Gestures (Перевірка жестів вводу)

* Автор: Олександр Грищенко
* Версія: 1.2
* Сумісність з NVDA: 2026.1 та новіші версії
* Встановлення: через Магазин додатків NVDA ([стабільна версія][1])

Пошук та виправлення конфліктів жестів вводу в NVDA та додатках. Жести вводу - це клавіатурні команди, команди брайлівських дисплеїв і жести сенсорних екранів.

Кожен встановлений додаток може додавати власні жести вводу або перепризначати наявні. Якщо той самий жест вводу прив'язано до кількох команд, працює лише одна з них, а інші не можна викликати цим жестом.

## Пошук жестів, що дублюються
Щоб знайти жести, що дублюються, відкрийте меню NVDA (NVDA+N), перейдіть до "Інструменти", "Перевірка жестів вводу" і виберіть "Пошук жестів, що дублюються...". Якщо дублікати знайдено, вони показуються у вікні у вигляді дерева:

* кожен дублікат - це гілка з його клавішами та розкладкою клавіатури в дужках, наприклад "NVDA+Shift+L (клавіатура, усі розкладки)";
* під клавішами - категорії команд, які їх використовують;
* під кожною категорією - команди: опис команди або назва її функції.

Спершу всі гілки згорнуті. Переміщуйтеся деревом клавішами зі стрілками; стрілки вправо і вліво або Enter розгортають і згортають гілку. Enter на команді відкриває діалог NVDA "Жести вводу" з цією командою та виділеним жестом, тож жест можна одразу змінити або видалити.

Жест для всіх розкладок клавіатури і той самий жест для поточної розкладки - це дублікат, бо обидва діють у поточній розкладці. Тоді біля клавіш показано обидві розкладки, а біля кожної команди - її розкладку. Однакові жести для різних розкладок, наприклад desktop і laptop, не є дублікатами, бо одночасно використовується лише одна розкладка.

Команди без опису не показуються в діалозі "Жести вводу", тому їхні жести там не можна змінити. Замість категорії для них показано назву модуля у квадратних дужках, а якщо вибрати таку команду, з'явиться попередження.

Пошук охоплює жести, доступні там, де зараз фокус: глобальні команди NVDA, глобальні плагіни додатків і програму у фокусі. Якщо пошук запущено з меню NVDA, це програма, яка була у фокусі до відкриття меню, як і в діалозі NVDA "Жести вводу". Жести, що діють лише в інших програмах, перевіряються, коли у фокусі одна з цих програм.

## Пошук під час запуску NVDA
Через кілька секунд після запуску NVDA, коли додатки вже завантажено, додаток шукає жести, що дублюються. Вікно з дублікатами з'являється лише тоді, коли є дублікати, яких ви ще не бачили, наприклад після встановлення додатку. Якщо нових дублікатів немає, нічого не показується. Знайдені дублікати залежать від програми у фокусі, тому переглянуті дублікати запам'ятовуються, навіть якщо під час запуску NVDA їх не знайдено.

* Гаразд - дублікати у вікні запам'ятовуються, і вікно з'явиться знову лише тоді, коли з'являться нові дублікати.
* Скасувати або Escape - дублікати не запам'ятовуються, і те саме вікно з'явиться знову під час наступного запуску NVDA.

Прапорець "Не показувати це вікно під час запуску" внизу вікна вимикає пошук під час запуску NVDA. Пошук з меню NVDA завжди показує всі дублікати, тож пошук під час запуску можна знову увімкнути тим самим прапорцем. За замовчуванням пошук під час запуску увімкнено. Після встановлення додатку всі наявні дублікати вважаються новими, тож якщо дублікати є, вікно з'явиться під час запуску NVDA.

Запам'ятовані дублікати і стан прапорця одразу зберігаються у файлі checkGestures.json у папці конфігурації NVDA, навіть якщо NVDA налаштовано не зберігати конфігурацію при виході.

## Жести без опису
Щоб переглянути жести, прив'язані до команд без опису, відкрийте меню NVDA, перейдіть до "Інструменти", "Перевірка жестів вводу" і виберіть "Жести без опису...". Такі команди не показуються в діалозі NVDA "Жести вводу", тому їхні жести там не можна змінити чи видалити.

## Команди
Обидва пошуки можна також запустити командою. Команди наведено в діалозі NVDA "Жести вводу", у категорії "Перевірка жестів вводу", де ви можете призначити їм власні комбінації клавіш. Комбінацій клавіш за замовчуванням вони не мають.

Щоб відкрити цю довідку, відкрийте меню NVDA, перейдіть до "Інструменти", "Перевірка жестів вводу" і виберіть "Довідка".

## Внесення змін до вихідного коду додатку
Ви можете клонувати цей репозиторій, щоб внести зміни до NVDA Check Input Gestures.

Вимоги:

* [uv](https://docs.astral.sh/uv/) - керує Python та всіма інструментами розробки додатку;
* [GNU Gettext tools](https://mlocati.github.io/articles/gettext-iconv-windows.html) (`msgfmt` і `xgettext` у `PATH`) - компілюють переклади та створюють шаблон рядків для перекладу.

Виконайте такі команди з кореня репозиторію:

1. `uv sync` - встановити залежності для розробки;
2. `uv run prek run --all-files` - запустити всі перевірки коду: лінтинг і форматування за допомогою ruff, перевірку типів за допомогою pyright та інші перевірки;
3. `uv run python -m unittest discover -s tests -v` - запустити модульні тести;
4. `uv run scons` - зібрати додаток, створений файл `.nvda-addon` розміщується в корені репозиторію;
5. `uv run scons pot` - створити файл `.pot` з усіма рядками додатку для перекладу (необов'язково).
